# EduPlas — Dokümantasyon (v1.1)
Sürüm tarihi: 2025-10-29

EduPlas, **“Öğren kazan, Öğret kazandır.”** mottosu ile geliştirilen, çok dilli,
yapay zekâ destekli bir öğrenme platformudur. Bu depo, proje içi dökümantasyonun
kaynağıdır.

## İçerik
- `PLAYBOOK.md` — Geliştirme standartları ve disiplin
- `ROADMAP.md` — Milestone planı ve sürümler
- `LEGAL.md` — Sözleşme/aydınlatma/kvkk izlekleri ve sürüm etiketleri
- `M1_BOOTSTRAP.md` — Bootstrap & Claims
- `M2_KONUM.md` — Konum A1
- `M3_KAYIT.md` — Kayıt & Telefon Doğrulama
- `ADR/` — Architecture Decision Records (ADR-001..)

## Roller (genel)
Baş Admin, İl Admin, İlçe Admin, Koordinatör, Öğretmen, Öğrenci, Destekçi.

## Temel İlke
